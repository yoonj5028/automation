SLIDE 01 / 06
AlphaGo · Principles
Background
How AlphaGo thinks
Every turn: read the full 19×19 board → evaluate → place the optimal stone. Decisions accumulate over time.
⊞

Global state evaluation

All 361 intersections are read as a single state tensor every turn. No position is skipped or estimated.

◈

Policy + Value network

Policy network proposes next move candidates. Value network scores the long-term outcome of each resulting state.

↻

Cumulative decision loop

Each stone placed stays permanently. History accumulates — every new decision builds on all previous ones.
